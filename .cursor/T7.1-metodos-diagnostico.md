# T.7.1 — Diagnóstico métodos (cards)

## Causa raiz (corrigida)

`StudyMethods` usava `goTo(\`/${m.id}\`)` para a maioria dos cards. Rotas reais estão em `src/app/router/routes.tsx` com prefixos `/metodos/...` ou slugs PT (`/analisador-documentos`, `/palacio-memoria`, etc.). URLs desconhecidas caíam em `path="*"` → redirect para `/`.

## Alterações feitas

- `STUDY_METHOD_ROUTE_BY_ID` em `src/views/methods/StudyMethods/StudyMethods.tsx` — mapa explícito id → path.
- **Spaced Repetition (`anki`)** → `/cards` (flashcards), não `/notas`.
- Rotas novas (meme / GOD MODE com componente existente sem rota): `/o-arquivo`, `/mente-colmeia`, `/forja-neural`, `/alquimista-neural`, `/sincronia-neural`, `/nexus`.
- Wrappers com `useNavigate(-1)` para `onBack`: God Mode, Duelo Socrático, e os componentes acima.
- **PremiumGate**: texto auxiliar “Toque para ver planos” no fallback.
