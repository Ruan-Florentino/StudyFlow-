## ETAPA 1 — Detecção CRLF / whitespace

Método aplicado a cada ficheiro:

- `git diff --numstat <ficheiro>` → linhas tocadas (insertions + deletions no numstat).
- `git diff --ignore-cr-at-eol --numstat <ficheiro>` → ignora CR no fim de linha.
- `git diff -w --numstat <ficheiro>` → ignora mudanças só de whitespace.

**Resultado:**

| Legenda | Critério | Quantidade |
|---------|----------|------------|
| 🔵 **CRLF-ONLY** | Diff normal não vazio, mas `--ignore-cr-at-eol` esvazia o diff | **0** |
| 🟢 **CONTEÚDO-REAL** | Diff com impacto mesmo após `-w` igual ao diff normal (só conteúdo “duro”) | **55** |
| 🟡 **MISTO** | `git diff -w` reduz inserções/remoções vs diff normal → mistura whitespace/CRLF + conteúdo | **8** |
