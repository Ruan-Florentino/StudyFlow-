# Study Flow

PWA de estudos com banco de 12k+ questões, simulados e estatísticas.

## Stack
- Vite + React + TypeScript
- Tailwind CSS
- Vite PWA (Workbox)

## Desenvolvimento
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Gerar ícones
```bash
npm run icons:generate
```

## Deploy
Configurado pra Vercel via `vercel.json`. Push pra main = deploy automático.
